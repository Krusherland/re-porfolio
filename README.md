# Cristian's React Portfolio

Welcome to my personal portfolio built with React!  
This project showcases my skills, projects, and passion for languages and technology.

## Features

- **Modern Design:** Responsive layout with custom CSS animations and effects.
- **Navigation:** Smooth navigation between sections using React Router.
- **Languages Section:** Visual representation of my language skills with interactive icons.
- **Projects:** Highlights of my work and experience.
- **Contact:** Easy ways to reach out.
